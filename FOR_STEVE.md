## 🚀 How to Deploy (3 Options)

### Option 1: Easiest — GitHub + Cloudflare Pages

1. Push to GitHub
2. Connect to Cloudflare Pages (automatic)
3. Site goes live at `ym-productions.pages.dev`

**Time:** 5 minutes | **Cost:** Free

### Option 2: Direct Upload

1. Log into Cloudflare Dashboard
2. Pages → Create Project → Direct Upload
3. Drag & drop the entire folder
4. Done!

**Time:** 2 minutes | **Cost:** Free

### Option 3: Manual via Wrangler CLI

1. Set up Cloudflare account
2. Get API token
3. Run: `npx wrangler pages deploy . --project-name ym-productions`

**Time:** 10 minutes | **Cost:** Free
