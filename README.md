# YOUR MOMENT PRODUCTIONS — Website

Professional website for YOUR MOMENT PRODUCTIONS, a veteran-owned creative production company.

## 🎬 Features

- **Responsive Design** — Mobile-first, fully responsive layout
- **Hero Section** — Split layout with circular badge seal
- **Service Grid** — 4-service grid with icons (Video, Photography, Editing, Creative Development)
- **Navigation** — Sticky navbar with smooth scrolling
- **Contact Form** — Functional contact form with validation
- **Modern Styling** — Gold accents, black background, premium aesthetic
- **Veteran-Owned** — Clear branding emphasizing veteran ownership

## 🎨 Design System

### Colors
- **Primary:** Black (#000000)
- **Accent:** Gold (#C4A853)
- **Text:** White (#ffffff)

### Typography
- **Headings:** Playfair Display (serif)
- **Body:** Inter (sans-serif)

## 🚀 Deployment

### To Cloudflare Pages

1. **Install Wrangler CLI:**
   ```bash
   npm install -g wrangler
   ```

2. **Authenticate:**
   ```bash
   wrangler login
   ```

3. **Deploy:**
   ```bash
   wrangler pages deploy . --project-name ym-productions
   ```

### Local Development

```bash
npm start
```

Visit `http://localhost:8000`
