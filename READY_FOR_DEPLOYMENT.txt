📋 DEPLOYMENT STEPS (Quick Reference)

FOR GITHUB + CLOUDFLARE PAGES:

1. Create GitHub account (if needed)
2. Create new repository "ym-productions"
3. Clone locally
4. Copy website files into repository
5. Commit & push to main branch
6. Go to https://dash.cloudflare.com
7. Click Pages → Create Project → Connect to Git
8. Select your ym-productions repository
9. Keep default build settings
10. Deploy!
11. Your site is now live at ym-productions.pages.dev
12. (Optional) Connect custom domain YMProductions.com
